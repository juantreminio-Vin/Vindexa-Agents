# Governing scale, ratios and O&M

**Rules (intent, not yet verified against code):**
- **Governing scale:** if an apprenticeship scale in a CBA conflicts with the registered apprenticeship program (RAP) document, the RAP scale governs.
- **O&M phase:** when a project moves to operations and maintenance, daily and overall apprenticeship ratio violation alerts are disabled. Percentage-based wage progression tracking stays active for any working apprentices. Existing contractor documentation rolls over.
- **Tests:** ratio (apprentice to journeyworker per day), participation, and labor-hours (against the required percentage). Apprentice certificates must be linked and the apprentice enrolled before rates are governed.

**Open:** thresholds by construction start date, and exact UI states. Verify before relying.
