# Document buckets: what upload alone does, and what needs a click

As observed on 2026-09-17, to be re-verified:

| Bucket | Upload alone enough? | Click needed |
|---|---|---|
| CBA | Yes, governs once extracted | Only Reject if wrong |
| Classification matrix | No, nothing exists until confirmed | Confirm the rows in the preview, then Approve or Override each job title |
| Fringe | Yes, governs on extraction | Optional review marks; only a REJECTED state blocks |
| Apprenticeship RAP | Yes for the math; the "RAP on file" gap stays open | Approve or Override extraction to clear the checklist |
| Apprenticeship certificates | No, not governed until linked | Review and link, then enroll the apprentice if not already enrolled |

Union status is a company-level record plus a per-project answer; check which scope an edit changes before changing it.
