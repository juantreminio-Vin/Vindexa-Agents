---
name: project-intake
description: Set up a new project's working notes from the template. Use when the human names a new project to audit or test.
---
Copy `templates/project/` into the human's `local/` folder (gitignored), not into the tracked tree. Fill the fact sheet from the evidence location the human supplies. Mark every value as Confirmed, Reported (stated but unconfirmed) or Conflicting (sources disagree, list them). Never store project data or links in tracked files. If a lesson generalizes, route it through `capture-knowledge` without the project's identity.
